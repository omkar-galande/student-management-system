# Student Management System

A RESTful Student Management System built using Spring Boot and MySQL.

## Tech Stack

- Java 21
- Spring Boot
- Spring Data JPA
- MySQL
- Maven
- Postman

## Features

- Add Student
- Update Student
- Delete Student
- Get All Students
- Get Student by ID

## Project Structure

```
controller
service
repository
entity
dto
exception
config
```
